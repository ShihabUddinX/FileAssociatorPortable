PortableFileAssociator v3.0.0.0 - File Types Association Filter

Improvement:
- Added an Association dropdown at the top of Configure File Types.
- Selecting an association name filters the File Type dropdown to extensions
  configured in that association's mode list.
- (All associations) displays every configured extension, preserving the
  previous all-types view.
- Extensions shared by multiple associations appear in each relevant group.
- Selecting a group automatically selects its first extension and loads that
  extension's existing settings. Changing the filter does not alter saved data.

The existing association, icon, host, New-menu, and template settings are kept.
